# MEDICAL-STUDENT-DATA-CLEANING-Python-Pandas

## Project Overview
This project focuses on cleaning and preprocessing a medical student dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project File
- `Medical_Student_datacleaning.ipynb` – Jupyter Notebook containing the data cleaning process.

## Objective
To improve dataset quality by identifying and handling missing values, duplicates, inconsistent data, and incorrect data types.

## How to Run
1. Download the notebook.
2. Open it using Jupyter Notebook or Google Colab.
3. Run the cells sequentially.
